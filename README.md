# Recall

> 잔상을 남긴 뒤 그 위치로 되돌아가며 공격하는 2D 액션 게임

## 소개

**Recall**은 이동, 점프, 대시, 기본 공격과 고유 스킬을 활용해
적과 보스를 공략하는 Unity 2D 액션 게임입니다.

플레이어는 대시로 남긴 잔상 위치로 순간이동하며, 이동 경로의 적을 공격할 수 있습니다.
이동 기술을 공격과 회피에 함께 사용하는 전투 경험을 만드는 것이 목표입니다.

## 개발 목표

- 1개의 스테이지와 보스전까지 완성
- 일반 적과 보스의 패턴을 활용한 액션 전투 구현
- 완성된 Windows 빌드 배포
- GitHub Issue와 Commit으로 개발 과정 기록
- 핵심 시스템을 직접 설명하고 수정할 수 있는 수준으로 구현

## 기술 목표

- **New Input System**으로 플레이어 입력 처리
- **Interface**를 활용한 공격·데미지 전달 구조 설계
- **ScriptableObject**를 활용한 캐릭터 능력치 데이터 관리
- **Object Pooling**으로 반복 생성되는 오브젝트 관리
- **Unity Profiler**를 사용해 실제 병목을 측정하고 개선
